### How to interpret user needs and implement them into a program?

To interpret user needs and turn them into a working program, I rely heavily on user stories with clear acceptance criteria. Breaking a large corporate vision down into user stories helps establish clear boundaries, allowing me to focus on creating specific features without getting distracted by scope creep.

### How to Approach Developing Programs?
When approaching a new development project, I prefer using an iterative Agile workflow over a rigid framework because it allows me to absorb requirement shifts smoothly. In my future development work, I definitely hope to carry forward practices like modular code structure and short, time-boxed feedback loops, which make codebases much easier to maintain when requirements change.

### What does it mean to be a good team member?
Ultimately, being a good team member in software development means prioritizing open communication, transparency, and a cross-functional mindset. Whether acting as a developer modifying java methods, a tester verifying system behavior, or a scrum master managing workflow tools, keeping your teammates aligned and supporting each other through changes is what drives a project to a successful release.
